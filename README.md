📦 Sistema de Controle de Estoque

Sistema web completo para gerenciamento de inventário e controle de produtos, desenvolvido com foco na organização de estoque para pequenos e médios negócios. Permite controlar entrada e saída de mercadorias através de um painel simples e intuitivo.

🔗 Acesse o projeto online: https://estoque.10001mb.com/?i=1



✨ Funcionalidades
- 📦 Gerenciamento de produtos (CRUD completo: criar, listar, editar e remover itens)
- 📊 Controle dinâmico de movimentação (entrada e saída de produtos em tempo real)
- 📊 Painel de controle responsivo e centralizado para administração ágil
- 🗃️ Integração dinâmica com banco de dados MariaDB para persistência de dados
- 🛡️ Tratamento de requisições e proteção de dados no envio de formulários
- 📱 Interface responsiva adaptada para telas de computadores e dispositivos móveis

🛠️ Tecnologias utilizadas
- PHP
- MariaDB / MySQL
- HTML5 / CSS3 (Bootstrap, Flexbox e Grid)
- JavaScript


📚 O que aprendi com esse projeto
Neste projeto aprofundei o controle de fluxo de dados com PHP e manipulação de relatórios e saldos em MariaDB. Pratiquei a estruturação de tabelas para controle de entradas/saídas, além de aprimorar a usabilidade criando um painel funcional com estilização limpa e responsiva.
